# Code of Conduct

gitvisualise is a welcoming project for people of every background and experience level, including people writing
their first pull request. We want it to stay that way.

## Our standard

Everyone participating in issues, pull requests, discussions and reviews agrees to:

- **Be kind and patient.** Assume good intent. Explain things; do not talk down to people.
- **Give and take feedback gracefully.** Critique the code and the idea, never the person.
- **Respect different skill levels, languages and time zones.** "Obvious" is not obvious to everyone.
- **Keep it on topic and professional.** No harassment, discrimination, personal attacks, sexualized content,
  doxxing, or deliberate disruption.
- **Credit others' work.**

## Enforcement

Maintainers may edit or remove comments, close or lock threads, and block people who break these rules. To report a
problem, contact the maintainers privately through GitHub (for example by messaging the repository owner or using
GitHub's "Report content" option). Reports are handled confidentially.

This Code of Conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), and
applies in all project spaces.
